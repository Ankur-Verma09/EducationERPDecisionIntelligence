# Replaceable Sprint 5 Mock Pilot Packages

Each child folder is a complete, versioned synthetic package. Consumers must select
a package by manifest `package_id` and verify every listed SHA-256 checksum.

Current package: `synthetic_reference_erp_v1`.

To replace it with a real pilot package, create a sibling version folder, retain the
same file roles, replace every mock policy and approval, and run independent design
review. Never edit a previously reviewed package in place.
